# Exploratory Data Analysis - Gunnels Dataset

## Overview

This project performs Exploratory Data Analysis (EDA) on the Gunnels dataset using Python and Google Colab.

## Phase 1 Tasks

- Loading and understanding the dataset
- Basic statistical analysis
- Missing data analysis and handling
- Data cleaning
- Data transformation
- Univariate analysis
- Bivariate analysis
- Multivariate analysis
- Correlation analysis
- Data visualization

## Tools & Libraries

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset

The dataset contains 1,592 observations describing gunnel presence and different shoreline and habitat characteristics.

Dataset source:
https://raw.githubusercontent.com/salemprakash/EDA/main/Data/Gunnels.csv

## Key Findings

- Gunnel presence is relatively rare in the dataset.
- No missing values were found.
- The data were explored using statistical summaries and multiple visualization techniques.
- Relationships between habitat characteristics, time, and gunnel presence were explored using bivariate and multivariate analysis.

## Files

- `Gunnels_EDA.ipynb` - Complete Phase 1 EDA notebook
- `Gunnels_Cleaned.csv` - Cleaned and transformed dataset
